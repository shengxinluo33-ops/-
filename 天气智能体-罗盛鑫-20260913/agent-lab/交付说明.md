# 智能体交互模型 · 交付说明

一套可复用的 Agent 骨架：把"用户 ↔ 智能体 ↔ 工具"的交互定成**状态 + 事件**，
再用网页把这个过程实时画出来。内置联网搜索、中断续问、会话持久化。

---

## 一、三步跑起来

```bash
cd agent-lab
pip install -r requirements.txt          # 1. 装依赖
cp .env.example .env                     # 2. 填入 API_KEY / BASE_URL / MODEL_ID
python app.py                            # 3. 打开 http://localhost:8000
```

`.env` 没配也能启动：页面顶栏会显示"未配置密钥"，此时 `/api/info` 返回
`ready: false`，发消息会收到一条错误事件，不会崩。

> 密钥优先级：先读 `agent-lab/.env`，没有再读
> `ch1-intro-and-toolcalling/notebooks/.env`（沿用课程里配好的那份）。

## 三、交互模型速览

**状态**：`idle → observe → think → act → (think…) → done / stopped / failed`

**事件**（前后端唯一契约）：

| 事件 | 含义 |
|---|---|
| `state` | 状态迁移 `{phase, turn}` |
| `token` | 思考的流式文本增量 |
| `tool_call` / `tool_result` | 决定调工具 / 工具回来了 |
| `stopped` | 被用户中断，已收手 |
| `done` / `error` | 正常结束 / 真失败 |

**三条设计规矩**：错误当数据（工具失败返回字符串让模型自愈）、
模型看不到 UI（核心不依赖任何 Web 框架）、历史可回滚（不留残局）。

## 五、已知限制

- **搜索后端**：默认走 Bing RSS。它必须带 `mkt=zh-CN` 才有精确结果（已在代码里带上了）。
  Bing RSS 擅长"精确文档"类查询（某份通知的全文），对"最近新闻"这类模糊查询
  只能给出一堆官网首页 —— 这类问题建议配 `TAVILY_API_KEY`，自动切换到 Tavily。
- **日期**：系统提示词会注入当天日期，否则模型会按训练截止年份去搜（实测搜出 2024 年的内容）。
  搜索结果也带发布日期，方便判断新旧。
- **抓网页**：百度百科 / 知乎 403（反爬），Wikipedia 在本机网络不通；
  政府站、门户站正常。打不开是常态，Agent 会换下一条链接。
- **会话存储**：单进程内存 + 本地 JSON 文件，适合教学演示；
  多人并发或生产场景需换成 Redis / 数据库。
- **并发**：同一个会话同时发两条消息会互相干扰（前端已用 `controller` 判忙挡住）。
